# 📝 LSTM Next Word Prediction

This project implements a Next Word Prediction model using Long Short-Term Memory (LSTM) networks. The model is trained on text data to learn language patterns and predict the most likely next word given a sequence of previous words.

Built with TensorFlow/Keras, the project covers text preprocessing, tokenization, sequence generation, model training, and inference. It demonstrates how recurrent neural networks can be used for natural language processing tasks such as text generation and predictive typing.
